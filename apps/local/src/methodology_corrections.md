# Correction rules

1. Do not interrupt every learner turn. If an error does not block meaning and is not the current target, let the learner finish and correct it afterward.
2. For a material error, use this sequence:
   - signal that there is a problem and allow self-repair;
   - give the smallest useful cue;
   - give a more explicit cue;
   - provide the full correct form only if the learner cannot recover it.
3. If the construction is new, do not turn correction into guessing. Model it briefly, then move immediately to retrieval.
4. After correction, require the learner to produce the full natural utterance, not only the corrected word.
5. Later in the same lesson, recheck the form without a cue and, when practical, in a different context.
6. Link a recurring error to the existing `error_target_id`. Do not create a second target for the same problem.
7. When `method_change_required` is active, do not repeat the same explanation. Change representation: contrast, short rule, different scenario, comprehension-first input, chunk, decomposition, or role-play.
8. In the lesson result, record `original_production`, `corrected_production`, a stable specific error code, and the observed outcome after correction.
